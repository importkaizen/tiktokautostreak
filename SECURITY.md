# Security

This tool stores TikTok web session data on the local machine under `~/.tiktok_streak_keeper/chrome_profile/`. Treat that directory like a password manager export.

## Reporting a vulnerability

Please **do not** open a public issue for security reports.

Email or message the maintainer through GitHub: [importkaizen](https://github.com/importkaizen). Include the affected version, a short impact summary, and steps to reproduce.

## What this project will not do

- Upload cookies, chat names, or logs anywhere
- Ship a hosted backend
- Ask for your TikTok password on the command line
